## 출처 등급과 각색 원칙

| 등급 | 의미 | 게임 반영 |
|---|---|---|
| 정사 | 김용 원작에서 확인되는 사건 | `강호연대기` 본편에 보강 |
| 비공식 이문 | 모이자 연재본 고유 사건·후일담 | 별도 외전 캠페인으로 분리 |
| 편집 오류 | 중복 업로드, 장 번호 누락, 깨진 한자·이름 | 사건을 합치고 표준 이름으로 정규화 |
| 제외 | 선정적 묘사, 강압적 관계, 반복되는 성인 장면 | 전투·정치·인물 선택에 필요하지 않아 사용하지 않음 |

원문 문장은 복사하지 않는다. 사건의 원인·선택·결과만 추려 게임용 새 대사와 임무로 각색한다. 모이자 연재본의 `단지홍` 표기는 원작 인물명 `단지흥`으로 정규화한다.

## 《화산논검》 계열 46편

### 서독 구양봉 1~6 — 36장

황약사와 일속 → 어둠 속의 바둑 → 황궁 어선방 → 원앙오진회 → 칼과 국자 → 백타산의 난쟁이 → 사막의 밤 → 사두장 구양적 → 얼음 동굴의 여인 → 백타산장 혈투 → 중원행 → 철장방의 패배 → 북국의 행로 → 유혹 → 합마공 → 유운장 폐허 → 최초의 살인 → 구음진경 추적 → 사랑과 원한 → 무림 고수들의 만남 → 종남산 결투 → 5년의 약속 → 구양봉의 귀환 → 모용쟁 구출 → 대사막의 주인 → 악은 악으로 → 사부의 유언 → 백타산장의 여인들 → 사랑의 위기 → 피못에서 태어난 아이 → 영원한 사랑.

게임 핵심은 백타산의 후계 다툼, 사막·빙굴 횡단, 합마공 완성, 철장방과의 충돌, 구음진경을 좇으며 서독으로 굳어지는 선택이다.

### 동사 황약사 1~6 — 36장

한 여인의 죽음 → 살인마 추적 → 천하 절색 → 용호의 울부짖음 → 독수리와의 싸움 → 늙은 악마와 처녀 → 미화와 병묘 → 사불과 악귀 → 풍악꾼 열여섯 자매 → 보물선의 구슬 → 황약사와 구천인 → 선악일념 → 황약사 처단령 → 두 제자 → 천하의 악인 → 곡절 많은 사랑 → 동방화촉 → 열여섯 자매의 수난 → 도화도의 사랑 → 결혼 → 서글픈 사랑 → 흑풍쌍살 → 다시 도화도 → 남제의 자비 → 우가촌 혈투 → 신력과 마력 → 전진칠자 → 구양봉의 계략 → 노완동과 영고.

게임 핵심은 살인 사건 추적, 해상 보물선, 구천인과의 첫 대립, 도화도 문하의 형성, 흑풍쌍살의 배신, 우가촌과 화산논검 전야다.

### 북개 홍칠공 1~7 — 29장

홍안루 → 강산이개 → 묘수인주의 위기 → 천하별미 → 두 절기 → 개방 방주 → 두 남매 → 애증의 인연 → 여인들 → 가짜 미립과 진짜 미립 → 운낭의 죽음 → 녹옥죽봉의 행방 → 장로들의 동요 → 남장 여인의 정체 → 게걸든 홍칠공 → 다리 잃은 미운산 → 절곡정의 주백통 → 거듭되는 위기 → 개방대회 → 개방의 먹구름 → 반쪽 옥벽 → 변한 인심 → 복수 → 미립의 죽음 → 보이는 적과 숨은 적 → 운의의 비애 → 와신상담.

게임 핵심은 개방의 두 계파, 녹옥죽봉 쟁탈, 가짜 방주 음모, 군산 개방대회, 방주가 되는 홍칠공의 책임이다.

### 남제 단지흥 1~7 — 36장

게임 핵심은 천룡사 비본 방어, 일양지 계승, 왕중양·주백통과의 교류, 화산논검, 황실의 책임과 사랑 사이에서 출가를 선택하는 과정이다.

### 중신통 왕중양 1~6 — 36장

기인 시장 → 생사를 건 강탈 → 검으로 구한 사람 → 세 의형제 → 죽음 앞의 왕중양 → 임조영의 함정 → 호남아와 미인의 운명 → 지하궁전 → 선천신공 → 명기의 정체 → 정충의 음모 → 반벽산장 혈투 → 여협과 무심공자 → 유일민의 사랑 → 임조영의 정체 → 무림대회 → 무림맹주 → 독사와의 사투 → 의형제 재회 → 모용준의 야심 → 철의법왕 → 임조영과의 이별 → 두 난쟁이 → 음모의 소용돌이 → 구음진경 → 낯선 강호의 바람 → 단지흥의 충고 → 종남산 혈투 → 활사인묘 → 모용준의 최후 → 활사인묘의 새 주인 → 임조영의 죽음 → 구음진경의 주인.

게임 핵심은 왕중양·임조영의 협력과 결별, 선천신공, 모용준·철의법왕의 음모, 활사인묘 소유권, 구음진경을 둘러싼 최종 선택이다.

### 풍류여마 매초풍 1~6 — 중복을 제거하면 25장

여씨 가문의 원한 → 흑풍쌍살 추격 → 무공 연마 → 소녀공 → 소요공자 → 소요관 결투 → 여혈의 구출 → 진현풍과 결별 → 해검계 무예시합 → 오혈궁의 비밀 → 변홍의와의 만남 → 동굴 구출 → 오혈궁 입문 → 내란과 음모 → 묘상의 최후 → 개방과의 공조 → 엽청청 추적 → 모녀 상봉 → 전진교와 소요공자 → 천산의 죽음 → 전진칠자와의 싸움 → 구원의 손길 → 오혈궁과 천산마궁 → 흑풍쌍살의 실종.

게시 1·2편, 3·4편, 5·6편에 같은 장이 다시 실려 있다. 게임에서는 한 번씩만 사용한다. 핵심은 매초풍을 단순 악역이 아니라 사문 배신의 빚과 여러 세력 사이에서 선택하는 시점 인물로 다루는 것이다.

### 신조협 양과후전 1~8 — 중복을 제거하면 32장

떨어지는 꽃잎 → 협객행 → 거와회 → 사주상박 → 취중 혼인 → 잘못 고른 남편 → 흩어진 사랑 → 숲속 혈투 → 백의 여인 → 협곡의 음모 → 미인 구출 → 양과로 변장한 양효비 → 황약사의 가르침 → 교언영색 → 오독방 → 칠월 초이레 → 철창묘 → 서역신교의 보물 → 인골염주 → 철혈남아 → 서역신교 전 교주 → 형제의 정 → 흐르는 인연 → 거와를 삼킨 양과 → 하룻밤의 인연 → 남해신니 → 여노악의 과거 → 모용세가 → 주백통 구출 → 모용협의 실체 → 교주의 탄생 → 백의 여인의 정체.

## 《의천도룡기》 본편 39편 대조

5. 주구진·주장령의 음모, 절벽 아래 흰원숭이와 구양신공
6. 육대문파 광명정 원정, 성곤의 음모, 건곤대나이, 명교 교주 추대

12. 의천검·도룡도의 비밀, 반원전쟁, 주원장과 장무기의 결별

### 현재 캠페인 감사 결과

이미 잘 반영된 부분은 각원의 구양 전승, 부모의 죽음, 장무기의 유년 한독·호접곡, 양불회 호송, 구양신공, 광명정과 명교 인물군, 만안사, 무당 태극, 영사도, 병기 비밀, 소림 결착, 주원장과의 결별이다.

수정할 부분은 다음과 같다.

- 기존 `무당산의 위기`는 성년 장무기가 현명이로와 다시 싸우는 허구가 앞선 유년기와 충돌한다. `주장령의 추격과 절벽` 전투로 교체한다.
- 기존 `호접곡의 손님`에서 금화파파가 너무 이르게 등장한다. `호접곡 환자 방어와 기효부의 부탁`으로 교체한다.
- 기존 `서역 사행길`의 성년 장무기·주지약 재회는 시간 순서가 흐리다. `구양신공 완성 뒤 광명정으로 향하는 육대문파`로 교체한다.
- 왕반산도의 도룡도 쟁탈, 녹류산장의 함정, 귀환선의 진상, 금강복마권은 이야기 카드만으로는 부족하므로 실제 전투를 보강한다.
