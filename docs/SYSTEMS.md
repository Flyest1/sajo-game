# 강호의 별 — 게임 시스템 설계서 (v3)

> 본 문서는 AI(Claude)가 작성했습니다.
> FE·조조전류 SRPG의 일반적 시스템 관습(장비/상점/거점/승급/보물)을 참고하되, 데이터·구현은 전부 자체 설계입니다.

## 1. 재화·아이템

- **금전(兩)**: 전투 승리 보수 + 보물 획득. 캠페인별 독립.
- **아이템 분류**
  | 종류 | 슬롯 | 예 | 효과 |
  |---|---|---|---|
  | 병기(weapon) | 유닛당 1 | 목검→철검→강철검→보검 | 공격+, 명중+, 필살+ |
  | 보구(acc) | 유닛당 1 | 호신부·옥패·경공혜·웅담환 | 방어/정신/이동/HP+ |
  | 영약(use) | 공용 행낭 | 금창약·대환단·해독환 | 전투 중 "도구" 커맨드로 사용 (행동 소모) |
  | 비급(key) | 공용 행낭 | 현문비급 등 | 승급 재료 |
- 행낭(인벤토리)은 부대 공용(조조전식). 장비는 유닛별 장착.

## 2. 거점(트영지) — 스테이지 사이 인터미션

캠페인 그래프의 `camp` 노드 또는 출전 화면에서 진입.
- **편성**: 협객별 카드에서 장비 장착/해제, 무공·내공 선택, 장착 후 능력치 변화, 공격/방어/파훼 자동 편성을 함께 처리한다. 760px 이하에서는 한 열로 재배치한다.
- **상점**: 구입 / 매각(반값). 스테이지 진행에 따라 품목 확장
- **특수 목표**: 섬멸·보스 외에 방어, 점거, 탈출, 비살상 제압과 둘 이상의 조건을 묶은 복합 목표 지원
- **보스 패턴**: 모든 보스가 외공·경공·내공 성향에 맞춰 HP 구간별 2단계 전술 전환. 다음 구간은 유닛 카드에서 확인
- **전장 표식**: 외공은 검격, 경공은 바람 날개, 내공은 기운 소용돌이 도형. 공격·무공·이동 의도도 한자 없이 별도 도형으로 표시
- **업데이트 적용**: PWA 새 버전 감지 시 화면 아래 알림의 `지금 적용`으로 저장 기록을 유지한 채 적용한다. 설정에서 버전 확인·새 버전 검사를 할 수 있고, 문제가 생기면 서비스워커 캐시만 비우는 `캐시 복구`를 사용한다. 이 과정은 통합 세이브와 체크포인트를 삭제하지 않는다.
- **행낭**: 보유 아이템 확인
- **출발**: 다음 스테이지로

## 3. 승급(클래스 진화)

- 조건: 레벨 N 이상 + 지정 비급 소지 → 거점에서 실행
- 효과: 클래스명 변화 + 능력치 보너스 + 신규 무공 습득 (예: 왕중양 → 中神通, 일양지 개안)
- 캐릭터 데이터 `promo:{lvl, item, cls, bonus, skill}` 로 정의. 주요 아군 전원에 단계적 적용 예정.

## 3-1. 무공 숙련

- 무공별 사용 횟수는 캐릭터·캠페인과 무관하게 전 모드에서 공유한다.
- 8/20/40/70회에 ★/★★/★★★/極 단계가 된다.
- 공격 무공은 단계마다 위력 배율 `+4%p`, 명중 `+2`; 회복 무공은 회복량 `+1`을 얻는다.
- ★★부터 기 소모 `-1`, 極에서 총 `-2`가 적용된다(최소 소모 1).
- 유닛 카드와 무공 편성 화면에 현재 진행도와 실제 적용 보정을 표시한다.

## 3-2. 원작 기반 내공·전투 특성

- 핵심 협객 12명은 내공·심법·경공·특성 중 1개를 출전 편성한다. 수치와 전투 효과는 `internals.js`에 한곳에서 정의한다.
- 원작에서 실제 이름이 확인되는 구음진경·구양신공·옥녀심경·북명신공 등은 해당 습득자에게만 배정한다. 이름난 내공이 없는 조민·소봉의 전투 성향은 `특성` 또는 운용 원리인 `심법`으로 표시해 가공 무공과 혼동하지 않게 한다.
- 곽정의 기본 선택은 구음진경이며 구양신공은 장무기에게만 배정한다. 곽정의 초기 수련을 표현할 때는 마옥에게 배운 전진현문내공을 별도 선택지로 사용한다.
- 캠페인은 완료·도달한 원작 사건으로 습득 순서를 제한한다. 아직 배우지 않은 선택지는 편성창에 도화도·검총·광명정 등 해금 사건을 표시하며, 비정사 도전인 천하논검에서는 모든 선택지를 개방한다.
- 효과는 능력치, 명중·회피, 조건부 피해, 피해 감소, 호신 파훼, 턴 회복·기력으로 구성하며 단일 조건 피해 +20%, 회피 +12, 피해 감소 20%를 데이터 안전 상한으로 검사한다.
- 승리 때 인물별 피해·호신 파훼·적 초식 간파·회복·피해 감수·격파·인연 협공을 기여 점수로 환산하고 최근 30전까지 저장한다. 기록 화면에서 최근 전투를 확인하거나 JSON으로 내보낼 수 있다.

## 3-3. 주요 적 전용 무학·간파·예고 행동

- `enemy-martials.js`는 주요 적 20명의 원작 무학, 행동 예고, 간파 조건, 전투 효과와 두 단계 패턴을 데이터로 정의한다.
- 플레이어는 적 정보창에서 다음 운용과 파훼법을 읽는다. 지정 무공 유형, 인접 협공 인원, 서로 다른 초식 연계 중 조건을 만족하면 간파가 발동한다.
- 간파는 추가 피해·명중·강기 피해를 주고 적에 따라 기력을 돌려받는다. 모용복의 두전성이는 간파하지 않은 단독 강공 일부를 비치명 반사한다.
- 성곤·정춘추·유탄지는 적중 시 기력을 깎거나 중독을 남기며, 구양봉·금륜법왕 등은 행동 조건에 따라 압력이 달라진다.
- `combat-rules.js`가 아군 내공 보정과 적 무학 간파를 순수 계산으로 처리해 전투 화면·예측·밸런스 시뮬레이션이 같은 규칙을 사용한다.
- R20 행동 8종은 `boss-actions.js`가 표적과 경고 타일을 한 번 고정한 뒤 축력·발동까지 같은 판정을 재사용한다. 전조 중 간파하면 데이터에 따라 행동이 취소되거나 피해와 범위가 약화되며, 모바일에서도 상단 의도 칩과 전장 먹선 타일을 함께 표시한다.

## 5. 통합 캠페인 엔진 (v3)

- **캠페인 선택**: 초대판 19전·본편·외전·도전을 한 레지스트리에서 제공. `stages_*.json`은 빌드 시 자동 발견되고 `campaigns.json` manifest와 대조된다.
- **통합 세이브**: `kimyong_save_v3` 안에서 프로필·캠페인·도전·최근 세션을 분리한다. v1/v2 원본은 유지하며, 손상된 구획만 격리하고 나머지는 계속 사용할 수 있다.
- **런타임 경계**: `Session`이 클래식·캠페인·도전 상태를 `BattleContext`로 변환하므로 전투 핵심은 저장 형식이나 캠페인 상태명을 직접 판별하지 않는다.
- **최근 여정**: `lastSession:{mode,campaignId,at}`을 공통 형식으로 기록한다. 타이틀에서는 유효한 캠페인·강호유람·천하논검을 한 번에 재개하고, 모든 진행 기록은 통합 허브에서 고른다.
- **자동 체크포인트**: 캠페인의 선택·출전·전투 직전 상태를 최대 12개 보관한다. 설정의 저장 검사 화면에서 손상 격리 사유를 보고 원하는 체크포인트로 복원한다.
- **스테이지 그래프**: 노드 kind = `battle`(전투) / `camp`(거점) / `choice`(루트 선택) / `end`(엔딩)
  - `next`: 문자열(단일) 또는 `{prompt, options:[{label, to, set}]}`(선택 분기)
- **플래그**: 선택지·전투 결과가 `flags`에 기록 → 이후 대사 조건행(`{if}`)·분기·엔딩 결정
- **전투 확장**: 출전 제약(필수/인원), 승리 보수(금전), 보물, 도구 커맨드
- **루트 맵**: 진행 그래프 시각화(클리어/현재/잠김/분기 갈래)
- **접근성**: 캠페인 단계와 현재 루트는 의미가 있는 버튼·`aria-current`로 표시한다. 모달 초점을 가두고 닫을 때 원래 위치로 되돌리며, 모바일 전투 핵심 행동은 안전 영역 하단바에 고정한다.

## 7. v3 전투·평판·그래픽 규칙

- 승리 조건은 `battle-objectives.js`, 보스 단계는 `boss-patterns.js`, 선택의 수치 효과는 `reputation.js`에서 순수 계산한다. 화면/세이브 코드는 결과만 소비한다.
- 본편 특수 목표전은 U6 군상극 추가전을 포함해 총 25개다. `validate_data.mjs`가 작품당 3개와 전체 12개 하한, 캠페인 자동 발견·manifest 일치 여부를 강제한다.
- 전투 캐릭터를 선택하면 이동 범위가 즉시 열리고 이동 칸·공격 가능한 적을 바로 누른다. 이동을 마치거나 제자리 캐릭터를 다시 누르면 행동 메뉴가 화면 최상위에 표시된다. 페이즈 시작 배너 중 입력한 첫 탭은 배너 종료 직후 예약 실행한다.
- 강호유람은 시드형 12~15노드 원정이다. 격전·객잔·기연·장터·문파 사건·최종 고수전을 포함하며 보물과 선택 효과는 실제 원정대 능력치에 누적된다. 완주자는 별호·흉터·여정 정보를 강호전설에 남긴다.
- 천하논검은 4인 편성·8관 연전이다. 관문별 보스·수하·호신·단계 초식은 `challenges.js` 데이터로 정의하며, 승리할 때 고른 심법이 부대 능력치에 누적된다. 관문 직전 상태와 최고 관문, 난이도·총 턴 기준 완주 기록을 v3 도전 구획에 저장한다.
- 전투 수수께끼 10제는 파훼·제압·점거·탈출·상성·생존·인연·복합 목표를 고정 부대로 푼다. 명중 100%·필살 0%의 결정론 규칙을 사용하고 턴·생존·피해·파훼·협공 조건으로 금·은·동 메달을 판정해 최고 메달만 보존한다.
- `俠` 2 이상은 아군 피해 -1, 점수당 상점 4% 할인(최대 20%). `情` 2 이상은 인연 전투 등급 +1. `勢` 2 이상은 공격 +1, 점수당 전리품 5% 증가(최대 20%). 가장 높은 문파 관계가 2 이상이면 명중 +4다.
- 문파 관계는 1/2/4/6점에서 인연/우호/동맹/맹약, 인물 신뢰는 호감/신뢰/의탁/생사로 상승한다. 신뢰 2 이상인 출전 협객은 명중 +3, 4 이상은 공격 +1, 6 이상은 방어 +1을 추가로 얻는다.
- 강호 회고는 분기 직전 전투·자원 상태를 되돌리지만, 기기 내 분기 열람 기록은 보존한다. 다시 만난 선택지와 회고 연표에서 확인한 분기와 미확인 분기를 각각 표시한다.
- 전장 테마는 `jianghu`, `jiangnan`, `taohua`, `xiangyang`, `guangming`, `shaolin`, `huashan`만 허용한다. 각 지역은 지형 판정과 별도로 깊이 레이어의 랜드마크·색조를 바꾼다.
- 반실사 초상 매니페스트는 `src/data/portraits.json`이다. 고유 원화 101명과 캠페인 별칭 27명을 합친 128명 모두 `hero` 768px와 `thumb` 192px WebP를 가지며, 주요 8명은 `expressions/{id}-{angry|hurt|awaken|smile}.webp` 32장을 추가로 가진다. PWA 핵심 프리캐시에서는 제외하고 최대 240개를 Cache First로 지연 저장한다. 이미지 실패 시 SVG 초상으로 대체한다.
- CI는 초상 파일 존재·용량, 테마 열거값, 특수전 수, 커스텀 보스 단계의 능력/호신 압력을 검사한다.
