# 강호의 별 v3 통합판 — 원작·이문·2차 창작 조사서

> 작성 기준: 2026-07-24
> 목적: 현재 구현을 원작 중심으로 재구성하기 위한 사실·판본·창작 경계의 기준 문서

## 1. 조사 원칙

### 정사 기준

- 한국에서 정식 완역된 김용의 2003년 세기신수판(3판본)을 기본 정사로 삼는다.
- 널리 알려진 1970~1980년대 수정판과 3판본의 차이는 `이문(異聞)`으로 기록한다.
- 연재 초판에서 삭제된 인물·사건은 본편에 섞지 않고 회상록 또는 선택형 이문으로만 다룬다.
- 소설 원문, 고유한 문장, 장문의 대사는 옮기지 않는다. 사건·관계·시대 배경을 새 대사와 전투로 재구성한다.

### 2차 창작 기준

- 정식 영상·게임 각색은 `각색 참고`로, 비공식 속작·위서는 `비공식 이문`으로 표시한다.
- 타 작가의 창작 인물·고유 사건·반전은 게임에 직접 가져오지 않는다.
- 원작이 남긴 공백과 실제 역사만을 바탕으로 게임 오리지널 외전을 새로 쓴다.
- 모든 게임 오리지널 캠페인 카드와 엔딩에 창작 범위를 명시한다.

### 출처 등급

| 등급 | 자료 | 사용 범위 |
|---|---|---|
| A | 김용 3판본 정식 출판 정보·작품 목차 | 정사 기준과 사건 순서 |
| B | 박물관·출판사·백과사전·역사 기관 | 판본 차이, 시대 배경, 인물 관계 교차검증 |
| C | 정식 영상·게임 각색 | 임무 연출과 시점 구성 참고 |
| D | 비공식 속작·위서·웹 팬픽 | 존재와 주제만 기록, 줄거리 직접 사용 금지 |

## 2. 현재 구현 감사

현재 게임에는 클래식 19장과 v2 캠페인 11종 75전투가 병렬로 들어 있다. 본편 네 작품의 v2 전투는 47개다.

### 구조적 문제

- 클래식과 v2가 같은 사건을 다른 분량과 규칙으로 반복한다.
- 클래식에는 장비·상점·인연·분기·캠페인 계승이 없고 v2에만 있다.
- 타이틀은 완성된 v2를 아직 `신규 캠페인 (베타)`로 취급한다.
- 각 캠페인이 작품의 대표 장면을 빠르게 훑지만, 주인공의 가치관이 변하는 연결 사건이 많이 빠졌다.
- 일부 엔딩은 정사와 IF의 경계가 화면에서 충분히 명확하지 않다.
- 완료 문구에 과거 개발 단계(R3~R6)가 남아 세계관 몰입을 깬다.

### 원작 대비 주요 누락·왜곡

#### 천룡팔부

현재 13전투는 세 주인공의 대표 사건을 압축했지만 다음 축이 약하다.

- 단예: 무량산 이후 목완청·종령·단씨 혈통, 천룡사와 구마지, 만다산장·왕어언, 모용복과의 대비
- 소봉: 행자림 전후의 신분 추적, 취현장, 아주의 변장과 소경호 비극, 요나라 남원대왕 시기, 아자·유탄지
- 허죽: 진롱기국, 무애자 계승, 만선대회, 천산동모·이추수, 영취궁과 서하의 인연
- 합류: 소실산에서 소원산·모용박·무명승으로 수렴되는 부모 세대의 업보
- 종막: 안문관에서 소봉이 전쟁을 막고 자결하는 정사 결말

현 구현의 소봉 생존 결말들은 유지할 수 있으나 반드시 `IF`로 분리하고, 정사 결말을 기본 축으로 복원한다.

#### 사조영웅전

현재 14전투는 중반 강호 유람은 잘 담았지만 곽정이 `영웅`이 되는 양 끝이 약하다.

- 구처기와 강남칠괴의 내기, 곽정·양강 두 가문의 대비
- 대막에서 철목진·철별·화쟁·제베와 맺는 관계, 흑풍쌍살 사건
- 비무초친과 목염자, 홍칠공 수련, 구양극과 완안홍렬의 지속적 위협
- 임안 황궁, 밀실 치료, 악양 개방대회, 무목유서 확보
- 도화도 참극과 황약사 오해, 철창묘 진상
- 화자자모 원정과 사마르칸트, 이평의 죽음, 학살 명령 거부
- 성길사한과 `영웅`의 의미를 두고 결별하는 마지막 대화

따라서 후반 몽골 원정은 선택 외전이 아니라 곽정 서사의 필수 종막으로 승격한다.

#### 신조협려

현재 10전투는 큰 이정표만 남아 양과의 오해·상실·성숙이 급하게 진행된다.

- 이막수의 등장, 가흥에서의 양과, 도화도 생활과 전진교 학대
- 고묘 수련과 옥녀심경, 왕중양 유각, 사제 관계를 둘러싼 사회적 압력
- 대승관 영웅대회와 금륜국사, 양과가 곽정의 인품을 직접 확인하는 과정
- 부친의 죽음을 둘러싼 진상 추적과 복수심, 곽정 암살을 포기하는 선택
- 절정곡의 정화독, 공손지·구천척, 양과의 단완과 신조·현철중검
- 양양의 갓난 곽양 구출, 곽부와의 갈등, 소용녀의 이별
- 16년 동안 신조협으로 활동하며 세 개의 금침과 곽양 생일 선물을 준비하는 사건
- 절정곡 재회, 양양 최종전, 몽케 격살, 제3차 화산의 새 오절

#### 의천도룡기

현재 10전투는 장무기 성인기만 빠르게 다뤄 세대 계승과 도검의 비밀이 약하다.

- 곽양·각원·장군보의 소림 서장과 구양진경의 세 갈래 전승
- 왕반산 도룡도 대회, 장취산·은소소·사손의 빙화도 10년
- 무당산 백세연과 부모의 죽음, 장무기의 현명신장 한독
- 호접곡 의술, 기효부·양불회, 주아, 주구진의 배신과 절벽 추락
- 구양신공 완성, 육대파 광명정 포위와 건곤대나이
- 녹류장·무당 태극·만안사 구출
- 영사도와 페르시아 명교, 소소의 선택
- 귀환선의 배신과 도검 분실, 주지약의 변화
- 소림 도사대회와 금강복마권, 사손·성곤의 결말
- 의천검·도룡도의 비밀과 곽정·황용의 유산
- 반원 세력, 주원장의 권력 장악, 장무기의 퇴장

주지약 단독 해피엔딩은 원작 엔딩이 아니라 명확한 IF로 이동한다. 정사 계열은 조민과의 약속, 주지약의 마지막 요구, 장무기의 열린 감정을 반영한다.

#### 월녀검

현재 캠페인은 한소영의 월녀검 전승에 집중하지만 원작 단편의 주인공은 춘추시대 월나라의 아청이다.

- 오·월 쟁패, 범려와 서시
- 백원과 겨루며 얻은 아청의 검
- 월나라 병사에게 남은 검법의 그림자
- 아청의 질투와 서시를 마주한 결말

한소영은 먼 훗날 전승의 흔적이라는 연결점이 있으므로, `아청 본편`과 `강남의 잔향` 두 시대로 나눈다.

#### 화산논검 전기·활사인묘·풍릉야화·후일담

이 영역은 원작의 짧은 회고와 공백을 확장한 게임 오리지널이다. 현재는 원작 사실처럼 보일 수 있어 다음처럼 분리한다.

- 정사로 확인되는 사실: 황상의 구음진경, 왕중양과 임조영의 관계, 제1차 화산논검 결과, 오절의 존재
- 공백: 오절의 젊은 시절 상세 만남, 논검 전의 공동 사건, 활사인묘 내부의 구체적 전투
- 게임 창작: 흑풍채, 황실 서고 쟁탈전, 특정 악역 연합, 시공 소용돌이

공백을 채우되 각 장 시작에 `원작 회고 기반 게임 오리지널` 표식을 붙인다.

## 3. 판본과 이문

### 정사에 사용하지 않을 구판 요소

- 사조 연재판의 진남금과 혈조 등은 수정판에서 삭제·통합되었다.
- 신조의 일부 실존 인물명은 3판본에서 가상 이름으로 바뀌었다.
- 의천 3판본은 결말의 감정선을 더 열린 형태로 조정했다.
- 천룡은 연재 중 예광이 일부를 대필했으나 수정 과정에서 대부분 제거되었다.

이 요소들은 `강호록 > 판본 이문`에 설명하고, 본편 사건을 혼합하지 않는다.

## 3-1. 핵심 협객의 무학 편성 기준

R15의 내공 편성은 인물의 이름값에 맞춰 임의의 절기를 나누는 방식이 아니라, 작품 안에서 직접 수련·전승·운용한 사실을 기준으로 한다. 명칭이 없는 전투 성향은 내공으로 만들지 않고 `특성`으로 분리한다.

| 인물 | 게임 선택지 | 원작·시점 기준 |
|---|---|---|
| 곽정 | 전진현문내공 → 구음진경 | 마옥에게 전진교 내공의 기초를 배우고, 도화도에서 주백통을 통해 구음진경 상·하권을 외운 뒤 수련한다. 구양신공은 배정하지 않는다. |
| 황용 | 기문둔갑 → 구음요결 | 도화도의 오행·팔괘·기문 운용이 먼저이며, 구음은 곽정과 함께 연구한 후대 선택이다. |
| 양과 | 옥녀심경 → 중검무봉 | 고묘에서 소용녀와 옥녀심경을 수련한 뒤, 단완 이후 신조의 인도로 현철중검과 해조 수련에 들어간다. |
| 소용녀 | 옥녀심경 → 좌우쌍검 | 고묘파 심법을 전승하고, 절정곡에서 주백통에게 좌우호박을 배운 뒤 옥녀소심검을 홀로 운용한다. |
| 장무기 | 구양신공 → 건곤대나이 → 태극심의 | 백원 뱃속의 비권으로 구양신공을 완성하고 광명정에서 건곤대나이, 무당에서 태극권검의 뜻을 이어 배운다. |
| 조민 | 백가박람 / 군주지략 | 특정 절정 내공의 정식 전승자가 아니므로 만안사에서 드러난 무학 식견과 여양왕부 지휘를 `특성`으로 표현한다. |
| 소봉 | 백전신위 / 항룡유회 | 이름난 중심 내공을 창작하지 않고 실전에서 드러난 담력과 항룡장의 여력을 남기는 운용 원리를 특성·심법으로 번역한다. |
| 단예 | 북명신공 / 능파미보 | 무량산 낭환복지에서 함께 얻어 익힌 두 절학을 흡기 지속전과 기동 회피 역할로 나눈다. |
| 허죽 | 북명진기 / 천산절학 | 무애자와 천산동모·이추수의 공력이 합쳐진 결과를 호체 진기로 표현하되, 단예처럼 직접 흡공하는 효과는 주지 않는다. |
| 주백통 | 좌우호박 / 공명권의 | 도화도에서 스스로 만든 분심이용과 지극히 부드러운 공명권의 운용을 각각 연계·수비 역할로 나눈다. |
| 왕중양 | 선천공 / 천강북두진 | 절정 내공과 전진교에 남긴 진법을 개인 파훼형과 협공 진형으로 나눈다. |
| 임조영 | 옥녀심경 / 전진파훼 | 고묘파의 핵심 심법과 전진 무학을 제어하도록 만든 초식 구조를 내공·상극 특성으로 구분한다. |

캠페인 해금은 레벨이 아니라 해당 사건의 완료·도달 여부로 판정한다. 곽정의 전진현문내공은 마옥 수련 뒤, 구음진경은 도화도 전수 뒤, 양과의 중검무봉은 검총 수련 뒤, 장무기의 건곤대나이와 태극심의는 각각 광명정과 무당산 사건 뒤 열린다. 천하논검은 비정사 도전이므로 모든 선택지를 처음부터 개방한다.

## 3-2. 주요 적 무학의 전투 번역 기준

적의 유명세에 맞춰 임의의 절기를 새로 배정하지 않는다. 작품에서 직접 사용·수련·전승이 확인되는 무학을 골라, 원문의 결과를 복제하지 않고 플레이어가 읽고 대응할 수 있는 `행동 예고 → 간파 조건 → 보상`으로 번역한다.

| 인물 | 원작 무학 | 게임 운용과 간파 |
|---|---|---|
| 구양봉 | 합마공·역구음 | 제자리 축력과 위기 폭발. 경공으로 축을 흔들거나 2인 협공 |
| 황약사 | 기문오행 | 진세·회피. 2인 포위 또는 서로 다른 초식 연계 |
| 금륜법왕 | 용상반야공 | 강맹한 장력과 강기 압박. 내공으로 흘리거나 연계로 호흡 차단 |
| 성곤 | 환음지 | 저기력 경맥 공격. 순양 계열 내공 또는 협공으로 암습 차단 |
| 구마지 | 화염도·소무상공 | 무형 도기와 절기 모사. 서로 다른 초식 연계 또는 다인 협공 |
| 정춘추 | 화공대법 | 산기·독공. 경공으로 접촉을 피하거나 빠른 연계로 중단 |
| 모용복 | 두전성이 | 비간파 단독 강공 반사. 동료 협공 또는 다른 초식 연계 |
| 구천인 | 철장공 | 강기 파괴 장력. 경공 회피 또는 양쪽 포위 |
| 매초풍 | 구음백골조 | 약한 상대 급습. 외공으로 정면 차단 또는 인접 호위 |
| 이막수 | 오독신장·빙백은침 | 원거리 독공. 내공 방어 또는 퇴로 봉쇄 |
| 유탄지 | 빙잠한독 | 기력 침식과 중독. 내공 방어 또는 연계로 운기 차단 |
| 멸절사태 | 아미검법·의천검 | 고명중 직선 검세. 외공으로 검로를 누르거나 연계로 교란 |

수치화할 때 조건부 피해 합계 +30%, 회피 +10, 반사 15%를 안전 상한으로 두고 자동 검사한다. 세부 파훼법은 원작의 승부를 그대로 재현했다는 뜻이 아니라, 각 무학의 서술된 성질을 SRPG 규칙으로 해석한 게임 디자인이다.

## 4. 비공식 속작·각색 조사

### 비공식 출판 속작

- 《교룡경사록》(창랑객/요비): 의천 결말 뒤 명교·페르시아·주원장과 장무기의 충돌을 확장한 비공식 속작.
- 《구음구양》(김용신/양삭/양명강): 의천 이후 대리 단씨 후예를 중심으로 구음·구양 계보를 결합한 비공식 속작.
- 《사조전전》·《신조전전》·《화산논검》 등: 1980~1990년대에 김용 이름과 유사한 서명·포장으로 유통된 위서 계열. 저자와 판본이 불명확한 경우가 많다.

이 작품들의 고유 줄거리와 인물을 사용하지 않는다. 대신 다음 질문만 게임 오리지널 외전의 소재로 삼는다.

- 장무기가 떠난 뒤 명교와 반원 세력은 누구의 것이 되는가?
- 주원장은 강호 세력을 어떻게 정치 권력 아래 편입하거나 제거하는가?
- 페르시아 명교와 중원 명교의 관계는 소소 이후 어떻게 변하는가?
- 구음·구양·도검의 유산은 새 왕조에서 축복인가, 재앙인가?

### 정식 각색·게임

- 1983년 TVB 《사조영웅전》은 철혈단심·동사서독·화산논검 3부 구성으로 장편을 명확한 막으로 나눈 사례다.
- 2024~2025년 《김용무협세계/화산논검》은 구음진경·동사서독·남제북개·오절쟁봉으로 원작 공백을 인물별 프리퀄로 확장했다. 세부 줄거리는 독자 창작이므로 직접 사용하지 않는다.
- 1996년 《김용군협전》은 서로 다른 시대의 작품을 게임적 메타 구조로 연결한 사례다.
- 2002년 《천룡팔부》 게임은 원작 인물 곁에 오리지널 주인공을 두는 방식을 사용했다.

게임은 이들로부터 `시점 분할`, `막 구성`, `메타 크로스오버`, `오리지널 관찰자`라는 형식만 참고한다.

## 7. 권리와 공개 배포에 대한 주의

이 프로젝트는 팬메이드이지만 인물명·관계·무공·사건을 직접 사용하는 공개 게임이다. 비영리·무료라는 사실만으로 개작권 문제가 자동 해소되지는 않는다. 현재 개발은 원문 복제 없이 진행하되, 대규모 공개 홍보·수익화·앱스토어 배포 전에는 권리자 허락 또는 전문 검토가 필요하다. 비공식 속작을 추가로 각색하면 권리 관계가 더 복잡해지므로, 외전은 실제 역사와 원작의 공백을 바탕으로 독자 창작한다.
