# 《화산논검》 7권 자료 수집·각색 입력표

## 현재 상태

지정된 네이버 블로그(`https://m.blog.naver.com/cgh1209/`)는 현재 개발 환경의 브라우저 보안 정책과 robots 제한 때문에 본문을 열람할 수 없다. 따라서 7권의 고유 인물·사건·반전을 추측해 게임에 넣지 않는다.

소스가 제공되면 기존 `화산논검 전기`를 그대로 덮어쓰지 않고 다음 순서로 반영한다.

1. 권별 사건표와 등장인물표 작성
2. 김용 원작 사실·원작 공백·해당 작품 고유 창작을 장면 단위로 구분
3. 기존 `stages_hwasan.json`과 충돌·중복 감사
4. 고유 내용을 `비공식 이문` 캠페인으로 분리하고 카드·루트·엔딩에 출처 표시
5. 대사는 원문 복사가 아니라 게임용 새 문장으로 각색
6. 데이터 검증·브라우저 스모크·빌드 통과 후 병합

## 제공 가능한 형식

- 가장 좋음: 7권 PDF·EPUB·TXT 또는 권별 블로그 글 내보내기 파일
- 가능: 각 권의 개별 공개 URL 목록
- 가능: 아래 표를 채운 권별 줄거리와 인물 메모

| 필드 | 내용 |
|---|---|
| 권·장 | 예: 1권 3장 |
| 시간·장소 | 사건 시점과 무대 |
| 시점 인물 | 장면을 따라가는 인물 |
| 핵심 사건 | 원인 → 선택 → 결과 |
| 새 인물·세력 | 이름, 관계, 목표 |
| 무공·물건 | 기능과 소유권 변화 |
| 원작 연결 | 원작 사실 / 공백 확장 / 독자 창작 |
| 이후 영향 | 다음 장·권에 남는 플래그 |
| 게임화 후보 | 이야기 / 선택 / 전투 / 거점 |

## 각색 게이트

- 7권 전체 사건표가 끝나기 전에는 일부 권만 본편 정사에 섞지 않는다.
- 출처를 확인하지 못한 요약은 `검증 대기`로 둔다.
- 김용 원작과 충돌하는 설정은 본편이 아니라 `비공식 이문` 분기로 보존한다.
- 개인 테스트 빌드에서도 정사와 팬픽의 출처 표시는 유지한다.
