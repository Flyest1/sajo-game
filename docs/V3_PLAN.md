## U0~U6 — 전체 통합

### U0. 정체성·정보 구조

- `v2`, `신규`, `베타`, 과거 R단계 문구 제거
- 새 게임은 강호연대기로 연결
- 캠페인 카드에 `원작 본편`, `원작 단편`, `원작 공백 기반 창작`, `비정사 도전` 배지 표시
- 천룡팔부와 사조삼부곡의 독립성, 사조 3권의 세대 계승을 지도에서 시각화

완료 조건: 첫 화면에서 플레이어가 클래식과 리부트 중 무엇이 본편인지 고민하지 않는다.

### U1. v3 세이브

```js
{
  version: 3,
  profile: { settings, achievements, stats, mastery, codex, reputation },
  campaigns: { [id]: CampaignState },
  challenges: { endless, roam, trials },
  legacy: { classicV1, importedV2 },
  lastSession: { mode, campaignId, at },
  checkpoints: { latest, history }
}
```

- 기존 `kimyong_srpg_save_v1`, `kimyong_v2_*`, 업적·숙련·설정을 읽어 최초 1회 복사
- 원본 키는 자동 삭제하지 않음
- 내보내기 파일에 스키마 버전·검증 결과 포함
- 잘못된 세이브는 전체 실패 대신 해당 구획만 격리

완료 조건: v1 클래식, v2 캠페인, 신규 사용자, 일부 손상 세이브의 자동 테스트 통과.

안정화 상태: 선택·출전·전투 직전 상태를 최근 12개까지 자동 보관한다. 설정의 `저장 검사·복구`에서 격리 사유를 확인하고 캠페인 체크포인트를 복원할 수 있으며, 격리 원본은 백업 파일에 계속 보존한다.

### U2. 캠페인 manifest·데이터 스키마

- 하드코딩된 `CAMPAIGNS`와 캠페인 카드 목록을 `campaigns.json`으로 이동
- 그룹·연대·정사 등급·선행 조건·계승·추천 레벨·기능 플래그 정의
- 스테이지 목표를 공통 구조로 확장: 섬멸·방어·구출·탈출·제압·점령·결투·동시 목표
- 그래프 도달성, 잘못된 플래그, 막힌 엔딩, 필수 인물 부재 검증

완료 조건: 새 캠페인은 스테이지 JSON과 manifest 메타데이터만 추가하면 소스 import 수정 없이 선택 화면과 세이브 허브에 나타난다.

### U3. 런타임 통합

- `G`, `V2`, `ENDLESS`의 역할을 `Session`과 `BattleContext`로 정리
- 전투 엔진이 모드 이름 대신 전달된 규칙·목표·보상만 사용하도록 변경
- 클래식 19장을 공통 캠페인 그래프에 연결
- 장비·인연·난이도·숙련·전투 예측을 모든 스토리 모드에서 동일 적용

완료 조건: 전투 핵심 경로에서 `if (V2)` 식의 모드별 기능 차단이 남지 않는다.

안정화 상태: `Session` 내부의 `campaignState`와 `challengeState`가 상호 배타적으로 상태를 소유한다. 화면 전환·전투·도전 코드는 이 저장소 또는 `BattleContext`만 사용하며 과거 `V2`, `ENDLESS` 전역은 제거했다. 모달 포커스 관리는 `ui-accessibility.js`, 체크포인트는 `checkpoints.js`, GSAP 모션은 지연 로드되는 `motion.js`로 분리했다.

### U4. 화면 흐름·UI

- 타이틀 → 강호연대기 → 권/막 지도 → 출전 → 전투 → 전후 선택의 일관된 흐름
- 최근 플레이 한 번에 이어하기
- 시대 두루마리형 캠페인 지도와 정사 등급 배지
- 모바일 하단 행동바, 키보드 포커스, 색상 외 문양을 병용한 위험 정보

완료 조건: 360px 모바일과 1920px PC에서 핵심 버튼이 겹치지 않고 키보드만으로 시작·저장·전투 가능.

구현 상태: 타이틀의 최근 여정은 캠페인과 진행 중 강호유람을 추가 선택 없이 재개하며, 모든 저장은 별도 통합 기록 허브에서 선택한다. 캠페인 화면에는 막 지도→거점→출전→전투→전후 단계를 표시하고 현재 루트와 출전 카드는 실제 키보드 버튼으로 제공한다. 전투 외 화면의 Enter/Space 기본 동작을 보존하고, 모달은 초점 진입·순환·복귀를 관리한다. 760px 이하 전투에서는 취소·위험·정보·턴 종료를 안전 영역이 적용된 하단 행동바에 고정한다.

### U5. 콘텐츠 이관·확장

- `V3_RESEARCH.md`의 누락 사건을 talk/choice/battle로 배치
- 사건을 모두 전투화하지 않고, 인물 변화가 필요한 지점만 조작전으로 구성
- 정사 결말과 IF 결말의 배지·색·해금 보상 분리
- 개발 로드맵 문구를 세계관 대사에서 제거

완료 조건: 본편 네 작품의 40/40/40/50회 핵심 사건 체크리스트에 미설명 공백이 없다.

### U6. 품질 기준

- 데이터 검증과 밸런스 시뮬레이션 강화
- Playwright 브라우저 스모크 테스트 추가
- 신규 시작, 이어하기, 분기, 패배, 보스 단계, 세이브 이관, 오프라인 빌드 자동화
- README·SYSTEMS·SCENARIO·PLAN을 v3 기준으로 동기화

## R13~R19 — 게임성 개선

### R13. 읽을 수 있는 전장

- 적의 다음 행동·목표·위험 범위 표시
- 행동 확정 전 예상 결과와 적 반격/특수효과 표시
- 구출·탈출·제압·거점·동시 점령·화재 확산·호위 목표
- 보스 패턴 타임라인과 전투 중 승리 조건 변경

### R14. 파훼·호신강기

- 강적에게 `호신`과 `기세` 게이지 부여
- 상성·측후면·제어·지형·인연 협공으로 파훼 수치 축적
- 호신 붕괴 시 한 턴의 파훼 창과 전용 연출
- 보스 2~3단계 패턴과 단계 전환 대사

### R15. 무공 편성·연계·합동 오의

- 출전 시 무공 3개 + 내공 1개 편성
- 초식 태그와 순서 연계
- 인연 A 및 특정 사건 해금 시 합동 오의
- 무공을 늘리기보다 캐릭터별 역할·리듬을 구분

3차 구현 상태: 핵심 협객 12명에 원작 행적을 근거로 한 내공·심법·경공·특성 25종을 정의했다. 곽정의 구음진경/전진현문내공과 장무기의 구양신공/건곤대나이/태극심의를 구분하고, 원작상 이름난 내공이 없는 인물은 가공 내공 대신 전투 특성으로 표기한다. 캠페인 습득 시점 잠금, 천하논검 사전 선택·중단 저장, 실제 피해·파훼·회복·격파·협공 기여도와 최근 30전 기록을 함께 지원한다.

### R16. 수묵 전장·UI 폴리시

- 전경·중경·원경 레이어, 날씨와 시간대의 전투 변화
- 먹선 궤적, 금색 파훼, 붓글씨 무공명, 보스 낙관
- 컷인과 표정은 데이터 기반 SVG로 생성
- 저효과 모드와 화면 흔들림·섬광 강도 옵션

구현 상태: 코드 생성 SVG 전경·중경·원경을 기존 전장 위에 합성하고, 도화도·양양·광명정·소림·화산에는 별도 랜드마크와 색조를 적용한다. 맵 스크롤에 서로 다른 비율로 반응하며 시간대는 3턴마다 이동한다. 고유 인물 101명의 독자 제작 반실사 WebP와 캠페인 별칭 27명을 합쳐 128명 매니페스트를 고해상도/전장용으로 나눠 지연 캐시한다. 주요 8명은 평상·분노·부상·각성·미소 개별 원화를 사용하고 나머지 인물은 기본 원화와 공통 감정 오버레이를 사용한다. 네트워크·파일 실패 시에는 전 인물의 기존 SVG가 즉시 대체한다. 무공·A급 합동 오의·보스 등장/단계 전환에는 반신 컷인과 낙관을, 실제 타격에는 유형별 먹선 궤적을 사용한다. 저효과 모드는 이 동작들과 날씨 입자를 생략한다.

### R17. 강호유람

- 10~15노드 로그라이크 원정
- 전투·객잔·기연·상점·문파 사건·고수 도전
- 4인 시작, 비급·보물 빌드, 시드 공유
- 완주 영웅의 별호·흉터·전설을 프로필에 기록

구현 상태: 시드로 4인 조합, 12~15개 노드, 장터 물품과 문파 사건까지 결정한다. 객잔·기연·문파 선택과 장터 보물은 원정대 능력치에 즉시 적용되며 엽전·승전·기연·보물·문파 관계를 노정 화면에서 함께 확인한다. 패배·전투 이탈 기록은 흉터에 반영하고, 최종 고수전 완주 시 네 협객의 별호·흉터·시드·노드 수·보물을 강호전설에 누적 저장한다.

### R18. 평판·문파·역사 회귀

- `협(俠)·정(情)·세(勢)` 평판
- 문파 관계와 인물별 신뢰
- 결말 뒤 이전 분기점으로 돌아가는 연표형 회귀
- 이미 본 대사는 요약 선택, 미확인 분기는 강조

구현 상태: 본편 선택 결과가 협·정·세와 문파·인물 관계에 함께 누적되며 관계록에서 중립→인연→우호→동맹→맹약, 낯섦→호감→신뢰→의탁→생사 등급을 확인한다. 인물 신뢰는 해당 협객의 명중·공격·방어에 단계적으로 반영된다. 강호 회고는 선택 직전 스냅샷을 복원하되 확인한 분기의 메타 기록은 보존하여, 재진입한 선택 화면과 연표에서 확인·미확인 분기를 구분한다.

### R19. 원작 무학 파훼·사건 성장·통합 편성

- 주요 적 12명은 원작에서 실제로 사용하거나 전승한 무학만 전용 특성으로 사용한다.
- 적 정보창에 무학 효과·행동 예고·간파 조건을 함께 표시한다. 무공 유형·협공·연계 조건을 맞추면 피해·명중·강기 피해와 기력 보상을 얻는다.
- 핵심 협객의 내공은 레벨이 아니라 마옥 수련, 도화도 전수, 검총 수련, 광명정·무당산 등 캠페인의 실제 사건으로 해금한다.
- 거점 편성은 장비·무공·내공·장착 전후 능력치와 공격/방어/파훼 자동 편성을 반응형 카드에 통합한다.
- 조건부 무공 계산은 `combat-rules.js`, 적 전용 무학 데이터는 `enemy-martials.js`로 분리해 전투 예측·실제 전투·밸런스 검사가 같은 규칙을 사용한다.

1차 구현 상태: 구양봉·황약사·금륜법왕·성곤·구마지·정춘추·모용복·구천인·매초풍·이막수·유탄지·멸절사태의 12종을 연결했다. 간파는 승전 기여도와 최근 전투 기록에도 남으며, 데이터 검증은 적 무학 수·파훼 경로·효과 상한·해금 사건 존재 여부를 검사한다.

### R20. 보스 전조 행동·사건 성장 피드백·배포 신뢰성

- 양강·구양극·공손지·학필옹·녹장객·금화파파·송청서·이추수의 실제 무학을 데이터와 캐릭터 무공에 교정·추가한다.
- 보스가 표적과 범위를 한 턴 전에 고정해 예고하고, 간파 성공에 따라 초식을 취소하거나 위력·범위를 줄인다.
- 전조 범위와 실제 판정은 같은 순수 계산 결과를 사용하며 PC·모바일에서 모두 읽을 수 있게 표시한다.
- 원작 사건으로 내공·심법이 열린 즉시 승전 화면에 무학명·효과·습득 사건을 보상으로 표시한다.
- 배포 번들에 `R20-<commit>` 식별자를 넣고, 저장 기록을 유지하는 업데이트 검사·PWA 캐시 복구와 CI 검증을 제공한다.

구현 상태: 주요 적 무학 20종 모두 실제 축력·발동 행동을 가진다. `boss-actions.js`가 표적 선택, 직선·십자·부채·범위 타일, 축력 진행, 취소·약화와 실표적 포함 판정을 DOM과 분리해 계산한다. 4인 밀집을 모두 덮는 행동은 재사용 대기 2턴, 그 외 행동은 1~2턴을 사용한다. 데이터 검증은 행동 수·무공 참조·범위·위력·밀집 적중·재사용 상한·실제 캠페인 보스 배치를 함께 검사한다.

## 구현 순서와 릴리스 게이트

1. U0~U2를 먼저 구현해 데이터와 세이브 기반을 고정한다.
2. U3~U4로 초대판과 리부트를 실제로 하나의 제품 흐름에 합친다.
