# U7 완결 감사

> 기준: 2026-08-13 · 상태: **U8 완료**

## U8 자료 기반 외전·본편 보강

- 모이자 지정 게시판의 화산논검 46편, 의천도룡기 외전 7편, 본편 39편을 장별로 구조화했다.
- 비공식 연재는 정사와 분리해 `화산논검 22권 이문` 7전투, `의천도룡기 외전` 8전투 캠페인으로 추가했다.
- 의천 본편의 시간 순서가 어긋난 3전투를 교정하고 왕반산도·녹류산장·귀환선·금강복마권 4전투를 보강했다.
- 중복 게시, 깨진 표기, 선정적 장면은 게임에 옮기지 않고 사건의 원인·선택·결과만 새 문장으로 각색했다.
- R26 공통 전투 잠금·복구와 U8 신규 캠페인은 자동 회귀검사에 포함한다.

## 완료 범위

- U0~U2: 원작 조사 기록, 캠페인 manifest, v3 비파괴 저장·이관·격리
- U3~U4: 단일 Session 전투 문맥, 캠페인/도전/회상 통합 화면 흐름, 모바일 접근성
- U5~U6: 본편 4권의 이야기·군상극 전투 보강, 자동 데이터·경로·밸런스·브라우저 검증
- R13~R18: 특수 목표, 파훼·호신, 무공 편성·합동 오의, 그래픽, 강호유람, 평판·문파 관계
- R19~R25: 원작 무학 간파, 전조 행동, 사건 성장·승급, 상호작용 전장, 본편 선택 환류전, 그래픽 4차, 무림 종장
- U7: 숙련·이동 계산 순수 모듈화, 빌드 청크 예산, UI 전역 핸들러·버전·테스트 목록 자동 감사

## 릴리스 게이트

1. `npm run validate`: 모든 캠페인 그래프·참조·좌표·규칙 상한
2. `npm run balance`: 대표 매치업, 보스 전조, 환경, 선택 변형, 종장 압력
3. `npm run test:smoke`: 데스크톱·세로 모바일 전 기능 회귀 116/116
4. `npm run build && npm run verify:build`: PWA 셸·버전·프리캐시·500KiB 청크 예산 (최대 350KiB)
5. `npm run audit`: 모듈 경계, 인라인 핸들러, 릴리스 식별자, 테스트 포함 여부

## 명시적 비범위

실시간 PvP·서버 계정·3D 엔진·원문 대량 복제는 제품 범위가 아니다. 과거 문서의 설득 영입·제3진영 NPC 호위·병기별 추가 상성은 승인된 U0~U7/R13~R25 로드맵의 미구현 항목이 아니라 향후 선택 가능한 후보로만 남긴다. 현재 로드맵에 필수 미구현 항목은 없다.
