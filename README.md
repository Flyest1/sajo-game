# 강호의 별 v3 통합판 (江湖의 별)

김용(金庸) 작품의 사건과 시대를 새 대사로 재구성한 비공식·비영리 팬메이드 SRPG · 한국어

**▶ 플레이: https://flyest1.github.io/sajo-game/**

초대판 19장과 리부트 캠페인을 하나의 `v3 강호연대기`로 통합하는 작업 브랜치입니다. 기존 저장은 삭제하지 않고 v3 저장소로 복사되며, 원작 본편·원작 단편·원작 회고 기반 창작·비정사 도전을 화면에서 구분합니다.

현재 v3 기반에는 통합 캠페인 manifest/세이브, 두루마리형 선택 화면, 적 의도·위험 범위, 점거·탈출·비살상 제압 목표, 호신강기·파훼·4대 본편 종장의 2단계 보스 패턴, 3개 무공 편성·연계·A급 인연 합동 오의, 협·정·세 평판과 강호 회고, 10노드 시드형 강호유람이 구현되어 있습니다. 본편 네 작품에는 정사 보강 이야기 51장면과 직접 플레이하는 군상극 추가전 17개가 삽입되어 있습니다.

U1~U3 기반 정리로 v3 저장은 구획별 검증·격리와 비파괴 v1/v2 이관을 지원하고, 백업은 쓰기 전에 전체 구조를 검사합니다. 캠페인 데이터는 `stages_*.json`을 자동 발견해 manifest와 대조·등록하며, 전투 핵심은 통합 `Session` 문맥을 통해 클래식·캠페인·도전 모드를 같은 규칙으로 처리합니다.

R16 그래픽 1차 업데이트로 전투 맵의 수묵 원경·중경·전경 패럴랙스, 3턴 단위 새벽·한낮·황혼·밤 변화, 전 인물 자동 표정(평상·분노·부상·각성·미소), 무공·합동 오의 반신 컷인, 먹선 공격 궤적, 보스 등장·단계 전환 낙관을 추가했습니다. 저효과 모드에서는 컷인·패럴랙스·날씨 입자·흔들림을 줄입니다.

R16 그래픽 3차에서는 기존 영웅·악역·문파 제자·병종 101명의 독자 제작 반실사 초상을 적용했습니다. U6 추가 전투의 캠페인 전용 인물 27명도 같은 고해상도 WebP 체계와 개별 SVG 대체 얼굴을 사용합니다. 곽정·황용·양과·소용녀·장무기·조민·소봉·단예는 평상 외에 분노·부상·각성·미소 개별 원화 32장을 사용합니다.

U3/R13~R15 후속 묶음에서는 캠페인 등록·보강 규칙과 승리 조건·보스 패턴·평판 계산을 전투 화면 코드에서 분리했습니다. U6 추가전까지 포함해 사조·신조·의천·천룡에는 총 25개의 제압·복합 구출·방어·점거·탈출 특수전이 있습니다. 전장 표식은 한자 대신 외공(검격)·경공(바람)·내공(기운)과 행동 예고 도형으로 표시됩니다.

원작·판본·비공식 속작 조사와 구현 기준은 [조사서](docs/V3_RESEARCH.md), 작품별 막·사건 설계는 [시나리오 바이블](docs/V3_SCENARIO.md), 단계별 범위와 완료 조건은 [v3 실행 계획](docs/V3_PLAN.md)을 봐 주세요.

PC · 모바일(터치) · 키보드 · 게임패드 · PWA 오프라인 플레이를 지원합니다.

## 개발

```bash
npm install
npm run dev        # 로컬 개발 서버 (모바일은 같은 네트워크에서 접속 가능)
npm run validate   # 게임 데이터 무결성 검증
npm run balance    # 자동 밸런스 시뮬레이션
npm run test:smoke # 데스크톱·모바일 브라우저 스모크 테스트
npm run build      # dist/ 프로덕션 빌드
npm run preview    # 빌드 결과 미리보기
```

  data/*.json            챕터·캐릭터·무공·지형·엔딩 데이터 (콘텐츠는 여기만 수정)
  gfx.js                 SVG 그래픽·반실사 초상 로더·타일·유닛 토큰
  battle-objectives.js   공통 승리 조건과 진행도 계산

  reputation.js          협·정·세 전투/상점/보상 효과

  game.js                전투 엔진 · 화면 흐름 (이동/전투/AI/무한 모드)
  save.js                v3 통합 저장·구버전 비파괴 이관

tests/smoke.spec.js      데스크톱·모바일 핵심 흐름 자동 테스트
public/portraits/        주요 인물 WebP 초상(고해상도/전장용)
