# 강호의 별 v3 통합판 (江湖의 별)

김용(金庸) 작품의 사건과 시대를 새 대사로 재구성한 비공식·비영리 팬메이드 SRPG · 한국어

**▶ 플레이: https://flyest1.github.io/sajo-game/**

초대판 19장과 리부트 캠페인을 하나의 `v3 강호연대기`로 통합하는 작업 브랜치입니다. 기존 저장은 삭제하지 않고 v3 저장소로 복사되며, 원작 본편·원작 단편·원작 회고 기반 창작·비정사 도전을 화면에서 구분합니다.

현재 v3 기반에는 통합 캠페인 manifest/세이브, 두루마리형 선택 화면, 적 의도·위험 범위, 점거·탈출·비살상 제압 목표, 호신강기·파훼·4대 본편 종장의 2단계 보스 패턴, 3개 무공 편성·연계·A급 인연 합동 오의, 협·정·세 평판·문파 관계·인물 신뢰와 강호 회고가 구현되어 있습니다. 반복 도전은 12~15노드 강호유람, 8관 천하논검, 고정 전술 수수께끼 10제, 영웅집결 무한 모드로 구성됩니다. 본편 네 작품에는 정사 보강 이야기 51장면과 직접 플레이하는 군상극 추가전 17개가 삽입되어 있습니다.

U1~U3 기반 정리로 v3 저장은 구획별 검증·격리와 비파괴 v1/v2 이관을 지원하고, 백업은 쓰기 전에 전체 구조를 검사합니다. 캠페인 데이터는 `stages_*.json`을 자동 발견해 manifest와 대조·등록하며, 전투 핵심은 통합 `Session` 문맥을 통해 클래식·캠페인·도전 모드를 같은 규칙으로 처리합니다.

U4 화면 흐름 통합으로 최근 캠페인·강호유람·천하논검을 타이틀에서 한 번에 이어가며, 막 지도→거점→출전→전투→전후 단계가 화면에 표시됩니다. 모바일 전투에는 취소·위험·정보·턴 종료 하단 행동바를 제공하고, 키보드의 기본 Tab/Enter 동작과 모달 초점 순환·복귀를 지원합니다.

R17 강호유람 2차에서는 캐릭터 선택 뒤 이동 칸이나 적을 바로 눌러 움직이는 기존 직접 조작을 유지하고, 이동을 마친 행동 메뉴는 세로·가로 화면 최상위에 표시합니다. 전투 시작 배너 중의 탭도 예약 처리합니다. 유람은 12~15노드에서 장터·문파 사건·객잔·기연·격전을 오가며, 엽전으로 산 보물과 선택 보정이 실제 전투 능력치에 적용됩니다. 완주한 4인은 별호·흉터·시드·보물을 지닌 강호전설로 영구 기록됩니다.

U3.1/U6.1 안정화에서는 과거 `V2`·`ENDLESS` 전역 상태를 제거하고 `Session`이 모든 플레이 상태를 직접 소유하게 했습니다. 선택·출전·전투 직전 자동 체크포인트 12개와 손상 격리 확인·복구 UI를 제공하며, 전 캠페인의 종막 도달성·백업 실복원·회고·패배 재도전·PWA 앱 셸 오프라인 검증을 CI에서 수행합니다. GSAP 연출은 필요할 때 별도 청크로 불러옵니다.

R16 그래픽 1차 업데이트로 전투 맵의 수묵 원경·중경·전경 패럴랙스, 3턴 단위 새벽·한낮·황혼·밤 변화, 전 인물 자동 표정(평상·분노·부상·각성·미소), 무공·합동 오의 반신 컷인, 먹선 공격 궤적, 보스 등장·단계 전환 낙관을 추가했습니다. 저효과 모드에서는 컷인·패럴랙스·날씨 입자·흔들림을 줄입니다.

R16 그래픽 3차에서는 기존 영웅·악역·문파 제자·병종 101명의 독자 제작 반실사 초상을 적용했습니다. U6 추가 전투의 캠페인 전용 인물 27명도 같은 고해상도 WebP 체계와 개별 SVG 대체 얼굴을 사용합니다. 곽정·황용·양과·소용녀·장무기·조민·소봉·단예는 평상 외에 분노·부상·각성·미소 개별 원화 32장을 사용합니다.

R18 3차에서는 본편 선택지에 문파 관계와 인물 신뢰를 확장하고, 관계 등급·전투 보정을 확인하는 `강호 관계록`을 추가했습니다. 회고로 과거 분기점에 돌아가도 이미 확인한 선택은 기억되며, 아직 보지 못한 분기는 금색으로 강조됩니다. 영웅집결과 진최종전은 특정 수령이 아닌 전원 퇴각 때만 패배하고 왕중양도 자유롭게 출전할 수 있습니다.

R19에서는 구양봉·황약사·금륜법왕·성곤·구마지·정춘추·모용복·구천인·매초풍·이막수·유탄지·멸절사태에게 원작에서 실제로 운용한 무학을 바탕으로 전용 행동 예고와 간파 조건을 부여했습니다. 유형 상성·협공·초식 연계로 간파하면 명중·피해·강기 파괴 보정을 얻고, 간파 횟수는 승전 기여도에 기록됩니다. 내공은 레벨이 아닌 도화도·검총·광명정 등 실제 사건 진행으로 해금되며, 거점 편성은 장비·무공·내공·예상 능력치·공격/방어/파훼 자동 편성을 한 카드에서 다루도록 통합했습니다.

R20/R20.1에서는 주요 적 무학 20종 모두에 원작 운용을 번역한 전조 행동을 연결했습니다. 표적과 범위를 먼저 고정해 붉은 먹선으로 예고한 뒤 같은 타일에 발동하며, R19 간파 조건을 전조 중 맞추면 초식을 취소하거나 위력·범위를 줄일 수 있습니다. 4인 밀집 범위기는 4턴, 나머지는 3~4턴 주기로 제한하고 사거리 밖에서는 일반 AI로 접근한 뒤에만 전조를 시작합니다. 사건 직후 새로 열린 내공·심법은 승전 보상에서 효과와 원작 사건을 함께 알리고, 앱에는 `R20-커밋` 식별자와 저장을 지우지 않는 PWA 업데이트 검사·캐시 복구 기능을 제공합니다.

R21에서는 핵심 협객 12명 전원에게 승급 경로를 마련했습니다. 기존 5명의 비급형 승급은 그대로 유지하고, 소용녀·조민·소봉·단예·허죽·주백통·임조영은 각자의 원작 사건을 완료하면 승급 계기가 열립니다. 승전 화면에서 새 성장 계기를 알리며, 거점 편성 카드에는 레벨·비급·사건 조건의 달성 여부와 실제 상승 능력치를 함께 표시합니다.

R22에서는 해상 급류, 양양의 번지는 불길과 파괴문, 광명정 지하의 독무·절벽, 서하 빙고의 이동 낙빙을 전투 규칙으로 추가했습니다. 환경은 양 진영에 동일하게 작용하고 매 라운드 결정론적으로 변하며, 지도 문양·선택 타일 설명·정보창에서 효과를 확인할 수 있습니다.

R23에서는 본편 네 작품에 원작 핵심 사건 전투를 한 편씩 추가했습니다. 사조의 임안 황궁 무목유서 추적, 신조의 몽골 군영 탈출, 의천의 영사도 성화진, 천룡의 요나라 사냥터 반란을 직접 플레이하며, 이전 선택에 따라 적의 압력·증원·보상이 달라집니다. 전투 시작 정보창의 `선택의 여파`에서 현재 적용된 결과를 확인할 수 있습니다.

도전 모드 완성 묶음에서는 12명 중 4명을 편성해 전용 관주 8명을 연속 상대하고 관문마다 심법을 선택하는 `천하논검`을 추가했습니다. 중단 저장·최근 여정·난이도·최고 관문·완주 논검록을 지원합니다. `전투 수수께끼`는 파훼·비살상 제압·동시 점거·탈출·상성·생존·인연·복합 목표 10개를 고정 전력과 확정 명중 규칙으로 제공하며 금·은·동 최고 메달을 저장합니다.

R15 3차에서는 핵심 협객 12명에게 원작 행적에 근거한 내공·심법·경공·고유 특성 25종을 편성할 수 있게 했습니다. 곽정은 전진현문내공과 구음진경, 장무기는 구양신공·건곤대나이·태극심의로 분리되며, 원작에 이름난 내공이 없는 인물에게 가공 명칭을 붙이지 않습니다. 캠페인에서는 습득 사건에 맞춰 순차 해금하고 천하논검에서는 시작 전에 자유롭게 선택합니다. 승전 화면과 기록에는 피해·파훼·간파·회복·격파·협공을 합산한 인물별 전투 기여도가 남습니다.

U3/R13~R15 후속 묶음에서는 캠페인 등록·보강 규칙과 승리 조건·보스 패턴·평판 계산을 전투 화면 코드에서 분리했습니다. U6 추가전까지 포함해 사조·신조·의천·천룡에는 총 25개의 제압·복합 구출·방어·점거·탈출 특수전이 있습니다. 전장 표식은 한자 대신 외공(검격)·경공(바람)·내공(기운)과 행동 예고 도형으로 표시됩니다.

원작·판본·비공식 속작 조사와 구현 기준은 [조사서](docs/V3_RESEARCH.md), 작품별 막·사건 설계는 [시나리오 바이블](docs/V3_SCENARIO.md), 단계별 범위와 완료 조건은 [v3 실행 계획](docs/V3_PLAN.md)을 봐 주세요.

회차(New Game+) 계승 보너스(자금/병기/인연 택1). 전투 UI: 정보창 유닛 반대편 자동 배치, 능력치 기본+장비 분리 표시,
무공 숙련도 진행도 표시, 전투 예측 예상 경험치(명중/격파) 표시.

PWA·조작성(R11): 홈 화면 설치 + 오프라인 플레이(서비스워커 프리캐시) · 앱 아이콘 · 키보드 조작(방향키/Enter/Esc/Tab/E) ·
게임패드 기본 대응 · 세이브 백업(내보내기/가져오기).

연출 고도화·밸런스(R12): 이벤트 컷신(SVG 배경 5종 + Ken Burns 팬, 클라이맥스 5종) · 전장 날씨(눈/비/운무/야전, 명중 보정) ·
캠페인별 BGM 테마(웅혼/비장/고풍/유현/장엄) · 자동 밸런스 시뮬(`npm run balance`, docs/BALANCE.md).

기존 R1~R12 콘텐츠는 삭제하지 않고 v3 공통 흐름으로 이관합니다. 본편의 누락 사건을 보강하는 U5 1차 연결 장면은 적용되었고, 신규 전투·선택 분기는 `docs/V3_SCENARIO.md` 순서로 계속 확장합니다.

## 개발

```bash
npm install
npm run dev        # 로컬 개발 서버 (모바일은 같은 네트워크에서 접속 가능)
npm run validate   # 게임 데이터 무결성 검증
npm run balance    # 자동 밸런스 시뮬레이션
npm run test:smoke # 데스크톱·모바일 브라우저 스모크 테스트
npm run build      # dist/ 프로덕션 빌드
npm run verify:build # PWA 앱 셸·오프라인 프리캐시 검증
npm run preview    # 빌드 결과 미리보기
```
